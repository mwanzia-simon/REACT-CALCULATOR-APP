# React Calculator

A simple and responsive calculator application built with **React**. This project provides an interactive interface for performing basic mathematical calculations.

## Features
- Addition, subtraction, multiplication, and division.
- Interactive calculator buttons.
- Clear input functionality.
- Responsive and user-friendly interface.
- Real-time calculation results.

## Technologies Used
- React
- JavaScript
- CSS
- HTML

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/mwanzia-simon/REACT-CALCULATOR-APP
   ```

2. Navigate into the project:
   ```bash
   cd REACT-CALCULATOR-APP
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

## Purpose

This project was built as a practical exercise to strengthen my understanding of React, component-based development, state management, and event handling.
